# DevOps по-тихому — рабочая тетрадь

Linux → Docker → Kubernetes → CI/CD → Terraform → Собес. Собирается в **один `index.html`** (открыть в браузере).
Подход — `METHOD.md`, порядок и статус тем — `ROADMAP.md`.

## Команды
```bash
npm run build   # src/ → index.html + artifact.html (публикуется: https://claude.ai/artifact/WcGVCuJ5wm6gjfoRzZmtUm)
npm run check   # сборка + проверка данных (пояснения, верные варианты, ссылки ↺ только назад, «странные» теги)
npm run map     # карта курса
```

## Навигация — что открывать для задачи
| Задача | Файлы |
|---|---|
| Новый модуль | `src/modules/L<N>/<id>.js` (образец — `L1/files.js`) + id в `src/course/order.js` + статус в `ROADMAP.md` |
| Формат модуля | `src/course/registry.js` (шапка) |
| Типы заданий | `src/engine/ex.js` (шапка) |
| Помощники текста: C, c, tbl, CMDS, TR, BOX | `src/core/helpers.js` |
| Инструмент упомянут раньше своего модуля — объяснение | `src/core/terms.js` (TERMS: n, re, d, m) — блок в модуле появится сам |
| Экраны, прогресс, порог 60% | `src/engine/app.js`, `PASS` в `order.js` |
| Внешний вид | `src/shell/style.css` |

## Модуль = вкладки
Теория (что и зачем → суть → как тренировать → ловушки) · Практика (22–28 заданий) · **Лаба** (руками, без ИИ: подсказка → проверка → решение) · Собес (вопросы; общий раздел «Собес каждый день»). Команды из `cheat` попадают в общую шпаргалку.

## Важно при правках
- HTML в текстах: `<pid>` пиши как `&lt;pid&gt;` — `npm run check` это ловит.
- Обратный слэш внутри шаблонных строк — двойной (`\r`).
